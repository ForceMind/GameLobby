# W1 多语言底座 —— 交付记录（2026-09-05）

范围：玩家侧大厅（`client/src`，不含 `client/src/admin`）。**后台界面按需求保持中文，不做多语言。**

## 做了什么

- `locales/registry.js`：24 种语言的唯一事实来源（编码、BCP 47、自称、书写方向）。新增一种语言 = 加一行 + 加一个 JSON 文件。
- `i18n.js` 重写：按语言查表 → 英文兜底 → 遗留目录 → 键名，每一次回落都上报（开发期 console 告警，生产可换成埋点）。
- 目录结构从「中文原文作键、单向中→英」改为 `locales/<语言>.json` 的 `{稳定键: 文案}`。
- 格式化按语言绑定（`createFormatters`），替换掉 5 处 `locale === 'en'` 二选一分支；阿语/波斯语/孟加拉语/印地语固定为拉丁数字，波斯语固定公历。
- RTL：`dir` 属性随语言切换，阿拉伯语与波斯语生效。
- 语言选择器：接上原本是死代码的 `LanguagePicker`，由注册表驱动，24 种语言各自以自称显示。
- 语言来源优先级：URL 参数 → 宿主 App → 本地存储 → 浏览器语言 → 默认简中；宿主可通过 `joyloop:context` 中途切换。

## 迁移的实际规模（取证结果）

调研发现目录里 973 个键中：
- **261 个是活键**（真正会被玩家看到）
- 121 个只被不可达文件使用（赛事、直播、社交——本版本已移除，代码保留但不进入翻译范围）
- 591 个是无任何调用点的孤儿条目

所以实际迁移 193 个键，而不是 846 个。当前玩家侧目录共 394 个稳定键。

## 安全网

迁移前抓取了全部 973 个键在中英文下的渲染基线，迁移后逐键比对：**0 处渲染差异、0 个键丢失**。
浏览器实测五个页面在日语下零中文残留，中文与英文渲染逐字未变。

## 翻译内容的现状

中文与英文完整（394 键），其余 22 种语言为空，运行时回退英文。**这是刻意的**：翻译是内容，由译者或运营通过 W2 的后台翻译模块填入，不由代码编造。`translationCoverage()` 已可给出每种语言的覆盖率与缺失键清单，供 W2 直接使用。

## 遗留待办

- 文案本身的问题（英文 gloss 错误、同一中文两个不同英文、把配置值写死进文案如「今日剩余 3 次」）单独处理，不与本次迁移混在一起，以免污染「渲染逐字不变」这条验证。
- 前台转盘奖项仍是页面内常量，尚未读取后台已发布配置（W4 处理）。
- 目录超过 512KB 时应改为按语言懒加载，已有测试守卫。
