v0.1.0 已补齐实际中英文切换、完整详情弹窗、昵称编辑、退出/访客/恢复、报名/候补禁用、兑换码两步确认和本页记录。八款游戏使用自包含 SVG 插画；未将游戏入口或记录演示冒充真实游戏与交易。最新操作契约和 126 组双语布局验收见 [QA.md](../client/QA.md)，部署见 [部署指南](../client/DEPLOY-CF-PAGES.md)。下方保留初版评审脉络。

## 当前交付

本版采用浅色、自包含的 React + Vite 重建，提供六个真实 HTML 入口：大厅、全部游戏、赛事、活动、商城、个人中心；根路径 `index.html` 是大厅别名，共七个构建入口。页面可在无后端条件下展示导航、组合筛选、轮播、弹窗、Toast、签到、抽奖、任务领取、兑换码校验、赛事报名提示、商城选择与个人设置切换等原型反馈。

金币与宝石是统一的演示资产命名。余额固定；业务交互状态只存在当前页面内存，刷新或切换页面即重置；语言偏好通过 URL / 可用的本地存储保留。购买、报名、领奖、兑换和退出不会提交服务器。

## 修订版吸收内容

- 大厅默认展示四款热门游戏，去掉“展开全部”折叠，提供独立全部游戏入口。
- `games.html` 完整展示八款游戏，类型、仅可进入、仅实时三组条件按 AND 组合；返回按钮直接回大厅。
- 游戏目录与最近游戏共用卡片和状态弹窗；最近列表支持键盘横向滚动与说明关联。
- 活动总览变成签到、转盘、每日任务的三个快捷入口，支持同页与跨页锚点。
- 签到奖励具备列表语义，任务按钮改为“领取奖励”，采用次级操作层级；页面级完成反馈随领取状态出现。
- 转盘新增可访问的奖项说明与抽取状态，签到、任务、转盘结果可在本页“演示奖励记录”中查看。没有把原型“同步到账单”当作已实现的服务端能力。

## 验收边界

本阶段验收包括：六个页面可相互到达；手机、平板与桌面无非预期横向溢出；确认、领取、筛选和设置有可见反馈；弹窗支持键盘操作；`npm run verify` 通过。构建生成可供 Cloudflare Pages 托管的 `dist/`，配置为 Root directory=`client`、Build command=`npm run build`、Build output directory=`dist`，也可直接上传 `dist` 目录。

2026-08-27 已检查六个页面在 360、390、430、600、820、1024、1366、1440、1920 宽度下的 54 组布局，无非预期横向溢出（最近游戏有意横向滚动的内容不计入）。已实测礼包合计、兑换码异常与成功、组合筛选、跨页锚点、领取后禁用、转盘次数、演示奖励记录、设置切换，以及弹窗键盘回绕 / Esc / 焦点恢复；浏览器控制台未观察到错误或警告。

## 已处理的问题

- 用真实多页面入口替代仅内存 Tab，刷新与分享入口保持一致。
- 金币 / 宝石术语统一，模拟动作不修改真实资产。
- 礼包明确基础数量、加赠数量和合计，卡片与确认页共用计算规则。
- 签到和任务按钮领取后禁用；转盘运行期间不可重复触发，指针与固定演示结果一致。
- 维护 / 即将上线 / 不可用状态有独立提示；游戏类型与“仅可进入”筛选可组合。
- 弹窗支持焦点回绕、关闭后焦点恢复、Esc 关闭；表单错误有辅助技术提示。

## 待产品确认

- 原型 D2 漏签、D3 可领，但文案声称“连续七日大奖”。漏签后是否重置、补签或累计尚无定论；当前明确标记大奖规则待确认。
- 赛事计分、平分顺序、重报名、候补扣费与退款规则缺少可执行定义。
- 月卡定价、续费、漏领补发与退款规则未给出，因此没有模拟开通成功。
- 如需逐像素还原原型美术，仍需补齐 `assets/` 或截图；当前包已采用自包含 SVG 主题插画，可独立部署。
- 如需宿主 iframe 嵌入，需确认宿主域名并调整默认禁止嵌入的响应头。

当前尚未发布到 Cloudflare，也没有连接真实账户或服务端。

后续实现正式产品前，应先确认设计稿资源、交互规则、资产/支付口径和服务端接口，再补充真实数据流与持久化测试。
