# 后台编辑交互统一 · v0.3.4

## 用户目标与已核实问题

页面保持预览，明确点击编辑才打开带子标签的编辑弹窗。先按运营工作流程设计，再实现。

- 基线：`9ce073b` / v0.3.3，`lobby-admin-lite-v1`。
- 浏览器实测：1440px宽时，游戏编辑按钮左侧1438px，表格可见右侧1404px，入口在滚动区外。
- 签到点编辑后main内出现14个数字输入，弹窗数量0；编辑器onChange直接更新共享store。
- 多种配置在详情抽屉直接编辑，弹窗分组主要为纵向字段堆叠。

## 交互决定

1. 页面与详情只读。查看打开只读详情；编辑使用明确按钮，表格操作列固定可见。游戏排序/推荐进入独立目录设置弹窗。
2. 编辑弹窗按任务分组子标签，不为每个字段造标签。页头、标签和保存/取消区固定，内容单独滚动。
3. 三种数据分开：生效版本、已保存草稿、弹窗未保存编辑。切标签保留临时数据，保存才写草稿/提交审核；取消不影响页面、队列或生效版本。
4. 页面默认生效预览；有草稿时提供明确的草稿预览，保存后显示草稿效果并标记待审核。
5. 有改动关闭时确认放弃；校验覆盖所有子标签，错误可定位到所属标签。没有改动不重复保存。
6. 运行状态与维护公告保留紧急操作边界；活动元信息、角色与玩家昵称等原有直接保存语义明确标注，不借本轮改造另建发布机制。退款/封禁/审核等为操作确认，不伪装成配置编辑。

## 拟分组

| 编辑对象 | 子标签 |
| --- | --- |
| 游戏 | 基础信息、进入门槛、大厅展示、Slots玩法参数（按类型）、变更预览；运行操作另开状态/影响弹窗 |
| 游戏目录 | 排序、推荐、变更预览 |
| 签到奖励 | 奖励梯度、规则说明、效果预览；从活动记录进入时另有活动信息和投放地区 |
| 转盘奖励 | 奖项配置、概率与次数、效果预览；从活动记录进入时另有活动信息和投放地区 |
| 任务 | 任务配置、奖励与状态、效果预览 |
| 商品/权益 | 按商品区分基础信息、价格/权益、效果或变更预览 |
| 多语言 | 基准文案、其他语言、变更预览 |
| 角色/玩家 | 资料或权限分组、变更预览；只读资料不变成可编辑 |

## 验收
