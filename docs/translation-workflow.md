# 多语言文案的翻译工作流程

适用：v0.3.7 运营后台原型（Pages 分支预览）「内容与语言 → 多语言内容」。这里管理玩家文案；后台界面仍为中文。

**当前是内存原型。** 编辑、导入、复核、审核与发布仅保存在当前后台页面会话，刷新或关闭会重置；不会实时同步玩家端，也不代表真实部署。玩家端仍使用应用内语言目录。真实多人协作、持久化、语言包分发和后台接口尚待补齐。

玩家端注册 24 个语种：简体中文是默认原文，英文是完整兜底基线；其余注册语种是否完整取决于各自目录覆盖率。注册不等于已完成翻译。

## 运营：选择范围并导出

1. 选择「当前编辑语言」。简体中文是原文维护；英文是参考及缺失翻译的兜底；其他语言是目标译文。表格中同一语言只显示一次。
2. 选择文案范围及翻译状态：全部、未翻译、待复核。可搜索键名、原文或目标译文，「只看已改动」会进一步缩小范围。
3. 核对「导出当前筛选（N 条）」的数量后导出。文件包含所有符合条件的记录，不只屏幕当前页。
4. 将 CSV 交给译者，并说明目标语言。只允许改「操作」与「译文」，其他列用于识别与冲突检测。

导出的是翻译任务文件，不是可直接发布的玩家语言包。文件保留了译文文本，但不是整套后台草稿/审核历史的备份。若刷新后基准已不同，需重新导出当前模板，将保留的译文复制到新模板再导入，不能强制覆盖冲突。

## 译者：填写文件

使用支持 UTF-8 CSV 的表格工具打开，保存时仍选择 UTF-8 CSV。保留以下九列表头、顺序及系统生成的内容。

| 列 | 填写规则 |
|---|---|
| 格式版本 | 保留 `joyloop-translation-v2` |
| 键 | 文案的固定标识，不能修改 |
| 命名空间 | 所属模块，不能修改 |
| 语言代码 | 目标语言，例如 `ja`，不能修改 |
| 简中原文 | 翻译依据，不能修改；维护中文时也只改最后一列 |
| 英文参考 | 参考与兜底文案，不能修改；维护英文时也只改最后一列 |
| 基准快照 | 系统生成的冲突检测数据，原样保留 |
| 操作 | 默认 `填写`；删除已有文案时改成 `清空` |
| 译文 | 填写目标文案，保留 `{coins}`、`{time}` 等占位符 |

- `填写` + 非空译文：更新对应语言；与现有内容相同则显示「译文未变化」。
- `填写` + 空白译文：跳过，保留现有内容。不要用空白表示删除。
- `清空` + 空白译文：明确删除对应译文。简体中文原文、英文兜底均禁止清空。
- `清空` + 非空译文：报错，避免操作含义不清。
- 文案可含逗号、双引号及换行，交给表格软件按标准 CSV 引用，不要自行拆行。

导出的公式形态文本（如以 `+`、`=` 开头）会带文字保护标记，避免在表格工具中作为公式执行。保留系统添加的标记，导入时会自动还原；不要启用文件中的外部链接或公式。

例如将目标语言设为日语，文案 `chest.balance` 的「操作」保留 `填写`，「译文」填 `コインが不足しています。`；其余系统列保持原样。

## 运营：回传与检查

1. 回到同一目标语言，选择「导入 ×× CSV」。文件最大 4 MB，记录数不能超过当前目录条数；较大任务按模块分批。
2. 检查逐条预览中的原有内容、回传内容及处理结果。预览每页 20 条，并显示更新、相同、跳过数量。
3. 错语言、未知语言、旧格式、列数不符、重复或未知键、占位符错误、原文或目标译文过期，均阻止整批导入。修正文件后重新导入；冲突请重新导出任务文件。
4. 若回传内容包含待复核译文，核对当前原文和英文参考后勾选确认。内容未变化也需要核对，不能只看更新数量。
5. 点击「确认导入会话草稿」。此时才写入目标语言；其他语言不被导入覆盖。确认前取消不会修改草稿；确认时会再次检测基准变化。

旧版五列 CSV 不再接受直接导入，避免重复中文/英文表头和“最后一列就是目标”的歧义。重新导出 v2 模板后，只迁移对应译文。

## 原文更新与复核

- 修改简体中文后，已有英文及其他译文进入待复核。
- 修改英文后，依赖英文参考的其他已有译文进入待复核。
- 编辑译文并保存，表示已依据当前原文完成修改；译文无需修改时，在编辑弹窗勾选「确认复核」后保存。
- 全部文案的「已填写覆盖率」与「待复核数量」分别统计。未填不等于翻译审核通过。
- 只要有非法文案或待复核译文，就不能提交模拟审核。允许先保存原文草稿，再逐步完成其他语言。

## 模拟审核与回滚

提交会生成含文案和复核依据的审核快照。进入「发布审核」查看逐条差异；批准时再次校验文案与复核状态，仅更新后台会话内的对照版本；可按现有原型流程回滚。处理较早的翻译审核任务时，较新的会话草稿会保留。

驳回规则按模块区分：通用配置驳回时重置来源草稿到生效版本；翻译任务仅在该快照之后没有新的翻译草稿时才重置，存在较新翻译草稿则保留。驳回原因必须填写。

这只验证操作流程，不能替代真实服务端存储、多人权限审核、语言版本分发或玩家端生效验收。
