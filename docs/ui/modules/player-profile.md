# 玩家侧 · 我的

## UI 与功能

“我的”展示头像、昵称、玩家 ID、等级、资产、最近活跃、奖励/消费记录、最近战绩和隐私设置入口。玩家 ID 可以复制，复制失败给替代提示。金币、宝石点击打开钱包详情；钱包列表支持完整模式下按类型、币种、收支筛选与分页，流水详情展示 ID、前后余额和处理状态。

区域顺序为页眉 → 资料 Hero → 资产卡 → 奖励流水 → 最近战绩。Hero 为头像、身份/昵称/可复制 ID、等级摘要和设置按钮；当前桌面头像 `72px`、白色 `5px` 描边、`23px` 圆角，Hero `22px` 内边距。资产为两张可点卡，金币/宝石分别用琥珀/青色圆形图标；完整流水在弹窗内先给类型、币种、收支筛选，再给条目和分页。半屏/窄屏将 Hero 与卡片改为单列或可换行，不能截断 ID、余额和设置入口。

隐私设置包含中奖通知、分享中奖和好友可见最近游戏。设置弹窗加载时展示状态，失败时保留重试；切换采用乐观更新，服务保存失败后回滚为原值并显示失败。奖励领取、月卡权益、宝箱记录与流水均为服务端/adapter 记录，玩家只能查看和筛选，不能编辑资产或状态。

## 数据与状态边界

当前动态资料通过 `useEngagement` 请求；默认 preview adapter 在浏览器 localStorage 持久化，server/宿主模式读取 `/api/v1/preferences` 和 `/api/v1/wallet/ledger`。玩家资料、等级、真实资产、战绩、月卡权益与头像的宿主来源没有当前真实接口证据。UI 不得把静态展示或 preview 余额写成已认证的账户事实。

流水加载、空记录、失败、筛选无结果、处理中/成功/失败状态需分别呈现。余额只随经过确认的服务快照或宿主上下文更新；页面本身不提供人工加减、退款、封禁或权益改写入口。

流水条目左侧是来源和时间，右侧为带正负号的金额与状态；完整弹窗可展开 ID、变更前/后余额。设置开关保存中锁定，失败后恢复开关原值并以文字说明失败；复制、打开资产明细和设置均需维持键盘焦点与弹窗关闭后的返回位置。

## 验收

- [ ] 资产入口、完整流水、筛选、分页、空态和失败重试均可用。
- [ ] 隐私设置保存中防重复，失败会回滚且不丢失错误反馈。
- [ ] 页面没有修改金币、宝石、等级、权益或历史记录的控件。
- [ ] `375px` 及半屏下资料卡、设置与流水详情可滚动、可关闭、焦点可达。

实现映射：`pages/ProfilePage.jsx`、`components/ProfileSettings.jsx`、`components/WalletLedger.jsx`、`engagement/useEngagement.js`、`engagement/service.js`。真实账户、资产、隐私、复制权限和宿主钱包接口未验证。
