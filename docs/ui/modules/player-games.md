# 玩家侧 · 游戏

## 目录与筛选

游戏页由全局分类和游戏类型两个独立维度组成。全局分类记录 `{ id, labels, enabled, sortWeight }`：`labels` 是注册 24 语的分类标签，`enabled` 控制已发布分类是否可在玩家筛选中出现，`sortWeight` 决定分类顺序。`all` 与 `popular` 是系统固定筛选，分别表示完整目录和热门推荐，不属于全局分类，不能由运营创建、停用或删除。

每款游戏通过 `tags` 关联已审核且启用的分类。新分类审核成功后才可在游戏编辑中选择；已有游戏关联的分类必须先迁移关联并完成对应审核，之后才允许停用或删除。分类一期只覆盖标签能力，分类审核依赖仍待定。

`gameType` 固定为 `slots`、`fishing`、`casual`、`other`，与 `tags` 无关。调整分类不会改变游戏类型、游戏引擎或会话入口。目录先按地区过滤，再按已发布分类、热门筛选和高级筛选过滤；地区不允许的游戏从目录和最近游戏中完全隐藏，国家未知遇到白名单游戏也隐藏；这不是锁定状态。

进入门槛用于已可展示游戏：财富等级、魅力等级、金币余额、可玩等级、允许性别、家族归属。任一已启用规则不能满足或玩家上下文缺失时，卡片显示锁和首条原因，详情显示全部原因，启动按钮禁用。维护、即将上线、暂不可用同样禁用启动；原因与地区不开放要分别说明。

区域顺序为页眉（眉题/标题/数量说明）→ 分类胶囊 → 高级筛选按钮与展开区 → 结果数 → 游戏卡网格/空态。分类胶囊横向可滚动；高级区至少包含“仅可玩”和清除动作，实时分类的快捷筛选使用该分类的已发布名称；停用或删除此分类后，快捷筛选一并隐藏并停止过滤。卡片封面在上、名称和分类/人数在下；状态覆盖封面而不挤压名称。锁定原因必须在封面以外重复为可读文字，不能只给图标或颜色。

## 详情与启动

点击卡片打开游戏详情：封面、名称、当前语言内容、状态、地区和门槛信息。游戏说明由简介、玩法、规则三段组成：简介按当前语言回退英文且必须有简体中文、英文；玩法和规则可整段缺省，存在任一语言内容时必须补齐简体中文、英文。三段都按纯文本显示，不能渲染运营录入的 HTML。

Slots 可额外显示中奖率、RTP、中奖金额范围和最大赔率四项详情属性。这些属性仅用于详情展示，不控制游戏引擎、投注或结算。`minBet`、`paylines`、`volatility` 尚未接入，不向运营开放编辑入口。`gameType` 决定详情展示属性，不控制游戏会话，不由分类推导。

底部动作顺序为次按钮“返回浏览”、主按钮“开始游戏”；只有状态 ready、地区允许、全部门槛通过时才能启动。不可启动时主按钮保持禁用而详情仍可关闭。

启动后由 `GameSession` 在当前大厅框内覆盖显示。先出现可取消的加载进度，再进入 Slots 转轴或休闲泡泡演示；回合完成会通知宝箱资格刷新。该会话是 UI 演示，不是已接入真实游戏引擎，也不能将分数或模拟回合视为真实资产结算。实时房间按钮会调用桥接；没有房间不可用，失败/已打开仅显示状态，真实房间硬件、协议和服务未验证。

加载层的返回控件置于安全区内左上，进度条有 `role=progressbar` 和百分比；游玩层关闭按钮同样在安全区内。会话内容使用框内纵向滚动，不能让加载、转轴、泡泡或实时房间按钮溢出 16px 桌面框或真机安全区。

## 预览与数据边界

浏览器仅在链接显式包含 `catalogPreview=1` 时，读取 localStorage 中已发布的 categories、游戏展示字段和游戏说明翻译。真实宿主和服务端必须忽略该参数与这些本地数据。已发布展示内容允许在刷新后保留；草稿、审核和回滚历史刷新后重置。

余额、门槛、运行状态、支付、活动和其他一般文案不通过此机制跨页同步。游戏说明草稿先由游戏管理入口保存，再到“多语言内容”提交审核；未通过审核的草稿不能作为上述本地已发布展示内容使用。

## 状态与验收

- [ ] `all`、`popular` 不出现在可编辑分类中；玩家只看到已发布且启用的运营分类。
- [ ] 新分类审核成功后才可关联游戏；停用或删除已关联分类前，关联游戏已迁移并完成审核。
- [ ] `gameType` 与 `tags` 独立；Slots 四项属性仅用于详情展示，未接入的 `minBet`、`paylines`、`volatility` 无编辑入口且不影响引擎。
- [ ] 简介具有简体中文和英文；玩法、规则为空时不生成空内容，存在内容时同样满足 zh/en；详情以纯文本渲染并按当前语言回退英文。
- [ ] 地区隐藏与门槛锁定可同时存在但不混淆；未知地区对受限内容 fail-closed。
- [ ] 详情必须再次校验状态、地区、全部门槛，不能通过历史链接或赢家点击绕过。
- [ ] 仅 `catalogPreview=1` 使用本地已发布目录内容；刷新不保留草稿、审核或回滚历史，宿主和服务端不读取预览数据。
- [ ] 加载、游玩、关闭、Escape、焦点循环和减少动态效果在全屏与半屏框内可用。
- [ ] 只有真实服务确认后才更新资产、战绩或宝箱资格；演示回合不得显示到账。

实现映射：`pages/GamesPage.jsx`、`GameCatalog.jsx`、`GameDetails.jsx`、`h5/GameSession.jsx`、`catalogPreview.js`。真实游戏启动、宿主账号字段与地区来源未验证。
