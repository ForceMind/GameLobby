# 玩家侧 · 游戏

## 目录与筛选

游戏页展示完整目录，支持分类（全部、Slots、休闲、实时）和高级筛选“仅可玩/仅实时”；大厅热门区只展示热门前四项。列表先按地区过滤，再按分类和筛选过滤。地区不允许的游戏从目录和最近游戏中完全隐藏，国家未知遇到白名单游戏也隐藏；这不是锁定状态。

进入门槛用于已可展示游戏：财富等级、魅力等级、金币余额、可玩等级、允许性别、家族归属。任一已启用规则不能满足或玩家上下文缺失时，卡片显示锁和首条原因，详情显示全部原因，启动按钮禁用。维护、即将上线、暂不可用同样禁用启动；原因与地区不开放要分别说明。

区域顺序为页眉（眉题/标题/数量说明）→ 分类胶囊 → 高级筛选按钮与展开区 → 结果数 → 游戏卡网格/空态。分类胶囊横向可滚动；高级区包含“仅可玩”“仅实时”复选框和清除动作。卡片封面在上、名称和分类/人数在下；状态覆盖封面而不挤压名称。锁定原因必须在封面以外重复为可读文字，不能只给图标或颜色。

## 详情与启动

点击卡片打开游戏详情：封面、名称、说明、Slots 的中奖率/RTP/中奖金额范围/最大赔率，以及状态、地区和门槛信息。底部动作顺序为次按钮“返回浏览”、主按钮“开始游戏”；只有状态 ready、地区允许、全部门槛通过时才能启动。不可启动时主按钮保持禁用而详情仍可关闭。

启动后由 `GameSession` 在当前大厅框内覆盖显示。先出现可取消的加载进度，再进入 Slots 转轴或休闲泡泡演示；回合完成会通知宝箱资格刷新。该会话是 UI 演示，不是已接入真实游戏引擎，也不能将分数或模拟回合视为真实资产结算。实时房间按钮会调用桥接；没有房间不可用，失败/已打开仅显示状态，真实房间硬件、协议和服务未验证。

加载层的返回控件置于安全区内左上，进度条有 `role=progressbar` 和百分比；游玩层关闭按钮同样在安全区内。会话内容使用框内纵向滚动，不能让加载、转轴、泡泡或实时房间按钮溢出 16px 桌面框或真机安全区。

## 状态与验收

- [ ] 地区隐藏与门槛锁定可同时存在但不混淆；未知地区对受限内容 fail-closed。
- [ ] 详情必须再次校验状态、地区、全部门槛，不能通过历史链接或赢家点击绕过。
- [ ] 加载、游玩、关闭、Escape、焦点循环和减少动态效果在全屏与半屏框内可用。
- [ ] 只有真实服务确认后才更新资产、战绩或宝箱资格；演示回合不得显示到账。
