# 玩家侧基础规范 · v0.3.4

本规范描述当前玩家大厅实现。业务导航固定为五页：大厅、游戏、活动、商城、我的；布局以 `client/src/version.js` 的 `v0.3.4` 为基线。本文档是源码核对，不构成硬件、宿主或 API 验收。

## 页面与入口

顶部提供返回/离开、品牌、金币和宝石入口。主导航按容器宽度切换：手机和模拟手机使用底部五页导航，不同时重复顶部桌面导航。资产按钮只打开钱包明细，不应在前端直接改余额。页面切换保留语言、模式与前一页滚动位置；路由切换会关闭已有弹窗和提示。每页都应有加载、空数据、失败、地区不可用和数据过期的明确画面；失败停留原页并给重试，不回退到本地成功结果。

## 独立原型说明入口

`index.html` 和带版本的新入口 是给评审和开发阅读的独立说明入口，不是玩家登录页，也不进入五个业务导航。没有显式 `lang` 参数时它默认简体中文；带语言参数时仍使用对应语言。它用于说明页面职责、数据边界和原型约定，不能将其后台字段、审核流程或样例数字混入玩家业务界面。

## 响应式判定

业务布局按 `.h5-lobby` 容器宽度判定，不能按电脑浏览器的1440px宽度直接选宽屏稿。375px手机和430px模拟手机都采用窄屏布局：游戏2列、最近游戏横向滑动、完整模式快捷卡2列、签到3列且大奖占整行、金币礼包2列、资产卡单列。桌面外框是否出现才使用浏览器视口和指针条件。

## 全屏、半屏与预览框

`mode=full` 为完整大厅，`mode=half` 为半屏入口。半屏高度当前为 `56vh`，并夹在 `50dvh–60dvh`；五项底部导航仍保留，内容收紧为优先任务和入口。完整模式在桌面细指针且宽度至少 `880px` 时使用通用手机预览框：最大宽 `430px`，**16px 圆角**，外框为 `10px/12px` 深浅描边；这是浏览器预览，不是硬件模拟。

完整模式可选 `auto / 18:9 / 21:9`。`auto` 依页面内容测量高度，最低 `480px`；固定比例共享受限高度，18:9 宽为高度一半，21:9 宽为高度的 `3/7`。在真实手机或非上述桌面条件下，页面全屏边到边，**不得显示假手机边框**。安全区使用 `env(safe-area-inset-*)`；桌面框最小上下 `12px`、左右 `8px`，游戏和弹窗同样不得遮挡安全区。

## 弹窗、焦点与状态反馈

普通弹窗、钱包、游戏详情和操作确认在当前大厅框内显示。打开模态或游戏时底层 `app-surface` 设为 inert；Toast 只在当前语言一致时显示，约 `2.8s` 后关闭。游戏会话是框内全尺寸对话层，加载阶段和游玩阶段均在该框内，Escape 可退出且 Tab 被限制在会话按钮内。

会改变资产、奖励或权益的按钮必须：先显示确认信息，处理中禁用重复点击，只在后端/宿主返回 `completed` 后显示成功；`cancelled`、`failed`、超时或 `unavailable` 不得伪造成成功。当前页面对未连接宿主/服务的行为在各模块中分别标注。

## 语言与地区

业务页支持 registry 中的 24 种语言。优先级为 URL `lang`、宿主上下文、已保存选择、浏览器语言、默认 `zh-Hans`；玩家可通过语言选择器改变并写入 URL/本地存储。缺翻译回退英文并在开发环境报警告；阿拉伯语与波斯语使用 RTL，金额数字按现有格式规则保持拉丁数字。`index.html` 和带版本的新入口 仅在没有显式语言参数时默认简体中文，这是说明页规则，不能外推为玩家页只支持中文。

地区由宿主上下文提供国家代码。全球配置始终可见；自定义白名单在国家未知或不匹配时 fail-closed。游戏和活动对地区不开放时直接不渲染，不显示为可点击灰卡。地区范围与进入门槛是不同层次，详见游戏模块。

## 数据来源与未验证项

静态包内数据用于页面文案、游戏目录、封面、说明和已发布活动配置。动态余额、宝箱、流水、赢家、隐私偏好等由 `useEngagement` 请求；默认使用可持久化到浏览器 localStorage 的 preview adapter，设置 `VITE_ENGAGEMENT_SOURCE=server` 或存在宿主时才请求 `/api/v1/*`。预览 adapter 不是实际服务。

硬件安全区、真实宿主语言/国家/钱包、支付桥、游戏引擎、实时房间、服务端资格、发奖、订单与网络错误画面均未做真实设备或 API 验收。UI 不得把样例余额、模拟转盘结果或预览本地状态标为真实到账；本轮源码核对也不构成这些能力的验证。
