# 游戏大厅 UI 规范与功能说明

本目录只面向 Joyloop 玩家游戏大厅的 UI 设计、前端开发和评审。它核对的是当前玩家版 `v0.3.4`：五个业务页的布局和交互已实现，本文档记录其 UI 基线与功能边界。当前发布版本以页面标记为准，本目录仅交接玩家游戏大厅。

## 阅读顺序

1. [玩家侧基础规范](./player-foundations.md)：全屏/半屏、桌面框、安全区、语言、状态、数据来源和独立说明入口。
2. [大厅](./modules/player-lobby.md)：首页入口、最近游戏和赢家动态。
3. [游戏](./modules/player-games.md)：目录、详情、地区、门槛和框内游玩。
4. [活动](./modules/player-events.md)：签到、转盘、任务及演示边界。
5. [商城](./modules/player-store.md)：金币礼包、月卡、明日宝箱和支付边界。
6. [我的](./modules/player-profile.md)：资料、资产、流水、隐私和记录。

## 规格状态

- **已实现 UI 基线**：五个玩家业务页、完整/半屏布局、桌面通用预览框、玩家语言选择、游戏详情与框内游玩入口均以 v0.3.4 代码为依据。
- **本轮工作**：文档核对与模块说明；不包含玩家布局改造。
- **单独验收**：真机安全区、宿主账户/国家/钱包、支付、真实游戏、实时房间和后端 API 仍需要相应环境验证，不能由源码检查替代。
