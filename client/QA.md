# v0.2.1 高保真原型回归验收

验收日期：2026-08-28。本版面向产品评审，直接呈现可点击的产品界面；不把账号接入、容器配置或开发说明放进入口流程。

## 本轮修正

- 删除说明页、同意勾选、进入门槛及相关样式和词条。旧会话的同意状态不再阻挡页面。
- 删除半屏/全屏缩放按钮。默认填满当前视口，1:1 半屏由展示容器或 `mode=half` 参数配置，不是用户功能。
- 顶部金币、宝石不再带“+”号或链接；统一原地打开资产浮窗，展示余额和最近变动。个人页资产卡使用相同行为。
- 关闭浮窗保留当前页面、锚点和已到达的滚动位置；不跳转商城、首页或说明页。
- 浏览器不显示无效的退出大厅按钮；原生宿主可用时才提供关闭能力。没有新增退出登录。
- 内部导航保留语言和有效的展示参数，避免依赖 `sessionStorage` 才能维持嵌入形态。

## 验证证据

- `npm run verify`：ESLint、26 项自动测试、生产构建、七个 HTML 入口与资源路径检查通过。
- 新浏览器标签页首次打开根入口：直接显示大厅、填满视口，没有说明页、同意控件、缩放按钮或资产加号。
- 七入口 × 金币/宝石 × 中英文 × 完整视口/1:1 形态，共 56 组资产浮窗检查通过。打开和关闭前后 URL 相同；弹窗在容器内，操作区可见，无横向溢出或英文残留中文。
- 另外实测个人页两种资产卡、战绩浮窗、四项主导航和四个快捷入口，均符合下方跳转契约。
- 在个人页战绩锚点、正文滚动位置 834px 处打开并关闭资产浮窗，URL 与滚动位置保持不变。
- 游戏加载中取消后等待超过加载时长，不会重新打开；正式进入后无左上 Lobby 控件，只有右上游戏关闭，关闭回到原页面。
- 检查环境包括 360×800、390×844、1280×720、1366×768，并包含 1:1 嵌入容器。

## 导航与浮窗契约

| 控件                                 | 期望行为                                 | 禁止行为                         |
| ------------------------------------ | ---------------------------------------- | -------------------------------- |
| 金币、宝石、个人资产卡               | 原地打开对应余额与最近变动浮窗           | 点击资产直接跳商城、首页或说明页 |
| 关闭浮窗、查看战绩/规则              | 保留当前页面；详情在浮窗内查看           | 重置入口状态或把页面导航到首页   |
| 主导航                               | 打开明确的大厅、赛事、活动、商城或个人页 | 目标丢失、先返回说明入口         |
| 全部游戏、任务对应游戏               | 打开完整目录并保留类型筛选               | 回到大厅热门区代替完整目录       |
| 免费旋转、每日任务                   | 打开活动页的 `#wheel` / `#tasks`         | 丢失锚点或跳回首页               |
| 最近战绩快捷入口                     | 打开个人页 `#records`                    | 跳到首页或丢失目标区块           |
| 品牌、大厅导航、全部游戏页“返回大厅” | 明确返回大厅                             | 将其他操作混用为该跳转           |
| 可进入游戏                           | 全视口加载 → 游戏自身界面 → 右上关闭     | 进入后保留额外 Lobby/缩放按钮    |

原型仍使用独立 HTML 入口，明确的页面导航会加载目标文档。它与“点击功能控件误回首页”不同；资产、详情、表单和游戏操作不承担导航。

## 自动测试覆盖

- 默认完整视口、无效布局回退、旧同意字段不再成为门槛。
- 活跃界面不再引用说明入口、同意状态、缩放控件或资产加号。
- 中英文词条覆盖、动态占位符、内链语言/布局参数/筛选/锚点。
- 美元礼包折扣、昵称校验、游戏组合筛选、兑换码分支、转盘角度。
- 宿主公共上下文校验、桥接失败/取消/超时、明确完成状态、请求标识。
- 游戏加载进度、窗口请求串行与最新排队请求覆盖。

## 数据与技术边界

商城继续使用 `1 USD = 10,000 金币`；四档购买价为 $0.55 / $2.46 / $4.90 / $7.68，金币数量不因折扣增加。完整配置见 [README](README.md)。

资产浮窗的余额来自当前钱包显示上下文，最近变动复用原型内的五条战绩数据；不是新接入的账单服务。奖励、报名、昵称、设置和回执仍是当前页面状态。

游戏采用本地加载及转轴/气泡交互。真实支付、原生 WebView 容器和服务端业务未在本轮联调；不会把本地回执当作真实账本。完整技术接口只维护在 [HOST-INTEGRATION.md](HOST-INTEGRATION.md)。

本轮检查针对本地生产构建，未执行 Cloudflare 线上部署；如线上仍显示旧说明页，应先核对实际部署包的源提交。

## 发布复核

1. 在 `client` 执行 `npm run verify`。
2. 使用 `npm run preview`；根入口应直接显示大厅。使用 `lang=zh/en` 检查两种语言，用 `mode=half` 检查嵌入形态，不增加界面开关。
3. 按上表实点浮窗、明确导航入口和游戏关闭，核对页面路径和状态。
4. 在干净提交上运行 `npm run package:pages`，核对 ZIP 完整性、逐文件哈希和 manifest 的 `version/sourceCommit/dirty: false`，用新包替换旧版本。
