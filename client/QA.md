# v0.1.0 静态交互验收

验收日期：2026-08-28。范围：六个页面、默认首页别名、简体中文和英文。结论针对当前静态构建，不代表真实游戏、交易、鉴权或任意浏览器环境的生产验收。

## 验证结果

- `npm run verify`：ESLint、9 项测试、生产构建、七个静态入口与资源路径检查通过。
- 中英文七入口 × 9 档宽度，共 126 组布局检查：无非预期横向溢出，页面语言标识正确；最近游戏有意横向滚动的内容不计入溢出。
- 宽度：360、390、430、600、820、1024、1366、1440、1920。对手机、平板和桌面关键界面进行了截图检查。
- 英文默认页面正文、提示与无障碍标签扫描没有残留中文；语言选项自身的中文名称作为语种名称保留。
- 32 组浏览器流程断言通过，覆盖下表各操作组、异常态与语言切换；未观察到浏览器控制台错误或警告。
- ZIP 打包执行 CRC 完整性测试，并解压后逐文件 SHA-256 比对；最终包的源提交与校验值在相邻 manifest 和 sha256 文件中。

### 规则与异常态

- 昵称：去除首尾空格后为 2–20 个 Unicode 码点；不满足条件时保留弹窗并显示错误。
- 默认活动可领 2 项：D3 签到和已完成任务。各自只可在本页领取一次，完成后总览计数减为 0。
- 转盘提供 3 次固定演示：800 金币、2 宝石、1 次免费旋转样例。抽取期间锁定按钮，完成后才扣减本页次数；奖励样例不会增加转盘次数或真实资产。
- 礼包总金币 = 基础金币 + 四舍五入后的档位加赠。四档合计分别为 6,480 / 35,400 / 87,040 / 179,200；币种始终为人民币，英文显示 CNY，不做换算。
- 兑换码：去首尾空格、忽略大小写。空值/未知/`USED-DEMO`/`OLD-DEMO` 均有错误；`JOY-DEMO` 校验成功不消耗，另点“演示兑换”后只可使用一次。修改输入会撤销前次校验状态。
- 页面刷新或切换会重置业务演示状态；语言偏好由 `lang` 参数优先决定，其次读取可用的本地存储，默认简体中文。所有内链带入当前语言。
- 切换语言后已有的兑换错误、礼包记录、奖励记录会重新翻译；异步抽取结果使用完成时的当前语言。

## 设计和产品限制

原型包未提供样式与图片，因此本版采用统一的自包含样式和八组 SVG 主题插画，不能宣称原型美术的像素级还原。字体、换行、状态、移动导航和触控区域已经按本包实现检查。

尚需产品确认：漏签如何影响 D7 大奖、赛事计分/同分/候补扣费/退款规则、月卡定价和漏领补发。未明确部分以演示限制或待确认说明呈现，没有自行制定真实业务规则。

当前只发布简体中文与英文。早期西语、葡语和菲律宾语文件已归档，不属于本次已验证语言。Joyloop、游戏专名与固定英文品牌标语不作机器式直译。

## 复核方式

1. `npm ci && npm run verify`。
2. `npm run preview`，分别以 `?lang=zh` 和 `?lang=en` 访问各页面。
3. 按上表验证默认、错误、已完成、禁用、取消、重复尝试和语言切换后的状态。
4. 在干净提交上运行 `npm run package:pages`；确认 manifest 的 `dirty` 为 `false`，校验 ZIP 后交付。
