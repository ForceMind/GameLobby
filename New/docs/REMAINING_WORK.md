# 剩余工作与生产化清单

当前版本已经具备可本地部署的前后端闭环：大厅、赛事、活动、商城、我的页面、二级详情、本地 Node 后端、后台管理、一键启动、一键验收、真实服务器 WebSocket 大厅接入。

## 已完成

- `cocogames` 品牌大厅。
- Slot 和 Casual 游戏列表。
- 移动端与 PC 端响应式布局。
- 赛事页：规则、人员情况、奖池、排名、奖励档位、详情弹层。
- 活动页：任务、进度、里程碑、奖励、详情弹层。
- 商城页：金币、活动道具币、道具、礼包、兑换结构。
- 我的页：资产、VIP、成就、钱包流水、礼物、消息、安全、客服、设置等二级页面。
- 货币规则：主货币为 `coins`，活动用道具币为 `eventCoins`，没有使用钻石、宝石等命名。
- 本地后端：`server/index.js` 提供 `/api/*` 和旧路径兼容接口。
- 本地数据：`server/mockData.js` 覆盖大厅、赛事、活动、商城、钱包、个人中心、榜单。
- 后台管理：`/?admin=1` 可查看和编辑内存 mock 数据。
- 一键启动：`一键启动.ps1` 和 `一键启动.bat`。
- 一键验收：`一键验收.ps1`，覆盖 lint、build、服务启动、核心 API、截图。
- 真实服务器：已验证 `/game/lobby/login` 返回 WebSocket，`InitRet` 返回真实用户、金币和游戏列表。

## 仍未生产化

## 1. 真实赛事、活动、商城接口

状态：需要真实业务后端补充。

已确认真实服务器当前可用的是大厅 WebSocket 链路，不是赛事、活动、商城 REST 链路。以下 REST 当前返回业务 404：

```text
/game/list
/user/profile
/user/balance
/arena/list
/activity/list
/activity/tasks
/store/products
/leaderboard/winners
/ws/token
```

后续需要真实后端提供：

- 赛事列表、赛事详情、报名、排行榜、结算、派奖。
- 活动列表、任务进度、里程碑、领奖、签到、转盘。
- 商城商品、订单、支付回调、发货、兑换码。
- 钱包流水、资产明细、奖励余额明细。

如果这些数据继续走 protobuf，需要提供消息名、字段、发送时机和错误码；如果改走 REST，需要按 `docs/BACKEND_MODULES.md` 的结构返回。
